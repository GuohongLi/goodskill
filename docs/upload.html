上传你的 Skill

任何人都可以上传。上传后你的 Skill 会进入注册表，被人和 Agent 浏览、下载、使用和评价。

方式一：在线提交（推荐，无需懂 Git）

填一个结构化表单即可。提交后机器人会自动处理并生成 Pull Request（约数小时内），管理员合并后即刻上线，全程免费。

你需要准备：slug（英文小写短横线名，如 my-skill）、展示名、一句话描述、分类、标签，以及一份可公开访问的 SKILL.md 原始链接（Gist / GitHub raw 链接均可）。

📤 去提交新 Skill

方式二：Fork + Pull Request（开发者）

Fork GuohongLi/goodskill 仓库，在 skills/ 下新建目录：

skills/<slug>/
├── SKILL.md      # skill 全文（触发词、流程、规则，一个文件讲清）
└── skill.yaml    # 元数据，格式如下
slug: my-skill
name: my-skill
display_name: 我的 Skill
description: 一句话说清它能做什么
category: 图像处理        # 如：图像处理 / 写作 / 编程 / 数据分析…
tags: [标签1, 标签2]
uploader: 你的名字
version: 1.0.0
trigger: 用户说什么话触发它
updated: 2026-09-29

然后发 Pull Request。合并后聚合脚本会自动把它收录进 api/v1/skills.json。

上线后会发生什么

① 进入技能库首页，可被搜索和筛选；② 生成专属详情页与 Agent API 地址；③ 任何人下载使用后可留下后验评价；④ 评分、好评率、token 消耗会被聚合展示——写得越实在、用得越好，排名越靠前。

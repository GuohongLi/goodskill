# Portrait Retouch（人像修图）

## Purpose
按专业人像修图流程修图，附带人像自动二次构图：一张原图可按不同景别裁出多张构图版本。默认风格为海马体风（高调通透、肤色粉白干净、质感扎实锐利），用户可指定日系、欧美、古风。触发词：用户说「人像修图」并附上人像照片。

**环境要求**：你的 AI 助手需要具备图像生成/编辑能力（能按指令重绘或编辑照片）。放大环节用高质量插值放大（如 Lanczos 2x）。

## 好修图的总标准（2026-09-27 平台作品研究沉淀，详见 ~/workspace/research_notes/portrait-retouch-mastery-20260927-0631/report.md）
商业修图师 Pratik Naik："修得好时，一半时间你根本看不出修过——这才是应该的样子。"好修图 = 一个人状态最好那天的样子：真实、自然、皮肤纹理清晰可见。所有技术指令都服务于这一条——任何一眼能看出"修过"的地方（塑料皮、发光眼、假牙、液化穿帮）都是事故，不是风格。学习样本：500px（Dmitry Arhar、Dani Diamond）、Behance before/after、1x.com、PhotoVOGUE。

## 风格选项（修图前确认，默认海马体）——风格只通过影调/肤色/对比度的技术参数体现
- **海马体（默认）**：定位是韩式的一个"精致商业分支"。一句话实操区别：**泛韩式清新是"整体柔"（抬黑、低对比、降清晰度、偏柔雾——这正是显模糊不干净的原因），海马体是"分区处理"——该柔的地方（皮肤、背景）柔到底，该锐的地方（眼睛、眉毛、发丝、人物轮廓）锐到位**，即"净而不糊"。高调通透、整体曝光偏右、高光接近溢出但保留细节；低对比、S 曲线高支点；整体饱和略降、肤色向粉白通透的"记忆色"修（比真实更粉更亮更低饱和，干净红润不假白）；阴影不死黑；背景干净简洁、轻微去饱和。质感铁律：皮肤纹理清晰、锐度扎实，绝不柔光糊化。证据边界：未找到海马体官方公开的任何具体修图参数，所有数值均为第三方教程建议范围。

### 先定管线：近景特写 vs 大场景
海马体技法是为"脸占画面大比例"设计的，景别一拉远就失效。修之前先定是哪一类：
- **A. 近景人像特写**（脸部像素充足），再按光环境分两种：
  - **A1 棚拍/可控光（海马体式）**：修的是"脸"：高低频或中性灰统一肤色（保留毛孔）、眼白去红黄不刷白、虹膜/睫毛/发丝局部锐化、牙齿去黄不纯白、液化单项 5–10 只微调。全局高调。
  - **A2 室外近景**：自然光、实景背景。面部提亮服从环境光（强度减半）；肤色保留环境光赋予的血色与色温，避免人物"贴上去"；背景保留氛围与识别度。
- **B. 户外大场景人像**（人物＋壮阔风景；修的是"光影关系与氛围"，2026-09-27 专项研究沉淀）：
  - **先定主次（C1）**：史诗风（Jonas Peterson 式）→风景是主体、人物是比例尺与叙事点，人物高度约占画面 1/10～1/5（作品观察归纳，非本人原话）；纪念碑风（Jimmy Nelson 式）→人物是主体占大比例、环境是舞台。两种是相反的主次关系，修之前先选一种。
  - **构图检查（C2–C8）**：先按"没有人物"构好风景，再定人物放哪里增强画面（PetaPixel）；人物放三分法交叉点/引导线汇聚点，或 Jonas 式对称构图（本人原话 "I'm a sucker for symmetry"）；视线方向留白多于反方向；前景占下 1/4～1/3、不挡人物，交代"前景→中景人物→远景"三层纵深；地平线按"天空/地面谁精彩"分配、不放正中；留白要有内容（云层渐变/远山/雾气），死白大天空=头重脚轻；人物小比例时用与环境跳脱的纯色服装（红裙 vs 蓝绿灰）；眯眼测试——眯眼看，人物消失=画面太散，需简化背景或用色彩/剪影/光斑给人物定位。
  - **用光标准**：首选日出后/日落前 1 小时；逆光脸黑四档预案——反光板 45°（+1～2 档）→曝光补偿 +0.3～+1.0EV→闪光灯 TTL −1～−2EV→机内阴影补偿"中"；"人物与背景同光"拆解为三要素：补光方向/色温/光质与环境光一致，人物比背景暗约 1 档是自然的，忌把人物提得比背景亮（=贴上去）。Jonas 原话：逆光发灰主因是直射光打到前镜片→偏离太阳稍许角度＋遮光罩＋点测光＋手挡镜头，再主动玩光斑；高光取舍"没有规则书，看意图"。McCurry 纪律：偏好低反差柔光、眼神光是铁律、按最亮想保留细节处欠曝（宁欠勿过）。
  - **后期流程（按 LR 顺序；参数均为社区/教程流传的经验试调起点，非官方标准）**：P0 镜头校正＋去污（100% 检查天空/人物边缘无脏点无彩边）；P1 白平衡先校肤色中性真实，再做一切颜色调整；P2 全局曝光：高光 −30～−70、阴影 +20～+35（**不超 +35**，否则氛围丢失）、白 −5～−25、黑 +10～+25、去雾 0～+10，全程看直方图防高光溢出；P3 天空压暗：渐变滤镜＋亮度范围蒙版只选亮部天空、曝光下拉；P4 人物提亮：主体蒙版/径向滤镜/画笔（羽化拉满），曝光 +0.3～+1.0EV（常用 +0.3～+0.7），污染背景用"减去天空/背景"限定蒙版；P5 氛围（可选）：径向滤镜圈光源方向、降去雾＋加色温造雾/金光；P6 曲线：轻 S，黑色可轻提 8～20 做胶片感；P7 HSL 分区：蓝（色相 −5～−15、明度 −10～−20 压深天空）、绿（色相 +15～+30 偏黄、饱和 −10～−20 去荧光）、橙/肤色单独建蒙版处理（色相 ±5、饱和 −5～−15、明度 +5～+20；太橙→升色相/降饱和/升明度，Cole's Classroom）；P8 颜色分级：高光暖（40～55°/饱和 10～20）、阴影冷（200～215°/饱和 5～15）；P9 先降噪后锐化：锐化 40～60、蒙版 40～60（只锐化边缘），天空轻锐化或不锐化；P10 磨皮极轻：人物蒙版内降 Clarity −5～−15、只去 transient 瑕疵、保留质感，看不清五官可省略；P11 收尾：胶片预设统一色调（Jonas 式 "finish it off with Alien Skin Exposure"——收尾定调而非前期大调），暗角 −5～−10，颗粒 15～30。
  - **三失败终检**：①天空死白——每次提亮必配高光压制（"局部控制代替全局推子"，Möhrle）；②人物贴上去——光向色温统一＋蒙版高羽化＋人物不比背景亮；③氛围丢失——阴影不超 +35、保留暗部深度。
  - **8 个常见错误**（反面清单）：人物比例失当（太大=游客纪念照、太小藏进背景）；地平线居中/死白大天空；逆光脸黑死或阴影 +100 拉出满屏噪点；补光与环境光脱节；无前景层次或前景超 1/3；色彩打架（荧光绿＋品红＋死白各行其是）；氛围丢失（提阴影＋去雾拉满＋压平对比）；基础失败（脱焦/抖动/高 ISO 噪点未处理）。
  - **执行方式**：B 管线优先走原像素确定性修图（曝光/曲线/渐变蒙版/色彩），100% 保留原始锐度；生成式重绘管线对远景脸部是重渲染、会丢微细节并可能改变身份，B 管线不依赖它。归因纪律：摄影师原话=事实，参数区间=经验试调起点，人物占比=作品观察归纳；Jonas 在 Exposure 中的具体预设参数未公开。
- 适用边界：特写★★★★★ → 半身★★★★☆ → 户外半身★★★☆ → 全身/环境★★☆☆ → 远景大场景★☆☆☆（走 B 管线）。
- **日系清新**：低对比、低饱和；阴影上提不死黑；整体偏青绿、高光加微青蓝、阴影藏灰绿；皮肤只提亮度不提饱和（"透明感"的本质），完整保留微纹理；空气感、自然情绪；减法构图、大量留白。
- **欧美**：强对比、S 曲线低支点；肤色受保护但整体饱和可更高；皮肤纹理强烈、毛孔可见；D&B 面部塑形更明显；轮廓立体、眉眼深邃；背景可带氛围感。
- **古风/中式**：雾面质感底妆、黑发适配；大气复古；弱化腮红、红唇点缀；影调沉稳。

## Workflow
1. **诊断**：先看画质——对焦是否在眼睛上（100% 放大眼睛必须清晰）、皮肤瑕疵（痘印/斑点/眼袋/泪沟/法令纹）、肤色问题（暗沉/偏黄/偏红/脸与脖子色差）、头发碎发、牙齿偏黄、曝光（面部死白或死黑）、噪点、背景杂物抢戏。再看构图——景别是否合适（特写/半身/全身）、眼睛是否在上三分线、头顶留白是否得当、是否在关节处裁切（脚踝/膝盖/手腕/肘部）、视线方向是否局促、人物是否居中呆板。
2. **自适应二次构图（先决策、再套模板）**：景别不是从模板里挑，而是由这张原图决定的。按顺序回答三个问题：
   a. **像素天花板**：量原图脸部像素高度和 100% 下的锐度（睫毛/眼神是否清晰）。脸部约 100px 以下 → 只能做环境人像版，不出特写/中景（硬裁=模糊或 AI 发明五官，见硬规则 1）。100% 下睫毛是糊的景别不存在，退回上一档。
   b. **这张照片最美的地方是哪里**：缩小全图看 3 秒——是脸（表情/眼神）？是手势/身体线条？是环境氛围？最美的是脸 → 向特写/头肩走；是手势/姿态 → 半身或 3/4 身、保留手部完整；是环境 → 保持宽幅、用负空间讲故事。
   c. **原构图是否已完整**：主体位置、负空间、视线方向都成立 → 不动，只做修图不做二次构图。二次构图是补救和强化，不是必做步骤；不确定时不动。
   定下景别后，每个版本明确目标画幅（人像常用竖画幅 4:5、3:2、1:1）、裁掉什么/保留什么、眼睛放在哪个三分点、留白安排，再用构图美学检查清单逐条自检。版本模板只是候选，不是必出清单：
   - **脸部特写版**：眼睛放上三分线交叉点，fill the frame；头顶要么不裁、要么大胆裁到额头（只蹭掉一线头皮像失误）；
   - **半身版**：胸上或腰上取景，人物放左下/右下三分点，视线方向多留白；裁剪点选两关节之间，绝不切手腕/手肘/脖子；
   - **环境人像版**：人物占画面 1/3 左右放三分法交点，用环境讲故事；背景杂乱则交代虚化；
   - **留白版**：人物偏向一侧，大面积干净负空间，适合做封面/文案。
   海马体构图偏好：干净背景优先，半身和特写为主，眼睛永远是视觉中心放上三分线，头顶留白适度不压抑，整体明亮通透。
   若原图构图已很好可只出 1 个版本；用户说"多裁几张"或一人多可用景别时出 2–4 个版本。
3. **定修图指令**：按专业人像流程顺序组织技术指令（总原则：修完看不出来修过）——
   白平衡先行（先定白平衡再谈风格）→ 校正（水平/裁剪）→ 曝光（面部提亮找回细节，高光不死白）→ 肤色统一（去偏色，脸/脖子/手臂色相拉向同一目标、只动明度和饱和，宁欠饱和勿过饱和）→ 瑕疵修复（痘印/黑头/结痂/脱皮彻底去；痣/疤/雀斑/美人痣默认保留或只淡化）→ 皮肤修饰（颜色均匀+纹理完整：只匀肤色不抹纹理，毛孔细纹清晰可见，绝不塑料皮）→ D&B 光影重塑（只增强原有光影逻辑，先判断光源方向：提亮额头中央/鼻梁/颧骨上方/眉骨/下巴/唇下三角，压暗鼻翼两侧/脸颊外侧/下颌线下方/发际线边缘/眼窝轻；违背光源方向=一眼假）→ 眼睛（眼白只做去红去黄的"清洁"不漂白；提亮只提眼神光对侧，提错侧=外星人眼；虹膜轻微加对比；眼袋泪沟减淡但保留下眼睑结构线；眼睛亮度服从主体光照逻辑）→ 鼻子（鼻翼两侧压暗、鼻梁提亮）→ 嘴唇牙齿（唇色红润自然；牙齿去黄为主、轻微提亮，绝不纯白）→ 头发（横过脸/眼睛的碎发必修、边缘碎发可留一部分；发丝锐化）→ 形体（液化只动脸型、个位数幅度：Chin Height +5~+15、Jawline −3~−8 绝不超过 −10、Face Width −2~−5；改完检查背景直线是否被带弯；标准是还认得出本人）→ 背景（杂乱则虚化/清理，有故事则保留；虚化过渡必须连续渐变，放大检查发丝边缘无抠图感）→ 影调统一（按选定风格的技术参数）。
   只写技术指令，不加风格化描述词；风格差异只通过影调/肤色/对比度的技术参数体现。
4. **执行**：每个构图版本用你的图像生成/编辑工具独立处理一次。给工具的 prompt 结构：
   - 第一行：用户原话（「人像修图」），原样保留不改写
   - Context 块：先写本版本的二次构图方案（目标画幅、裁剪取舍、眼睛位置、留白），再写选定的风格（海马体/日系/欧美/古风），最后按第 3 步顺序列修图技术指令
   - 附上原图作为输入图像，要求保持人物身份一致
5. **验图**：100% 放大检查——眼睛锐度（清晰有神、亮度服从光照逻辑、眼白干净不死白、眼神光方向正确）；皮肤纹理（毛孔绒毛可见、无塑料感）；肤色过渡（脸脖手臂一致无断层）；D&B 无脏斑块无油光；液化无穿帮（背景直线没弯、还认得出本人）；牙齿自然不抢戏；背景虚化在发丝边缘过渡连续、无抠图感；整体"看不出来修过"。没问题再进入下一步。
6. **分辨率检查与放大**：检查每个成品的最长边，若不足 2560px（2K）则做一次高质量插值放大（如 Lanczos 2x）。放大后快速复验无异常再交付。注意：放大只能改善观感，不能恢复原图不存在的真实细节。
7. **交付**：简述诊断出的问题，说明每个版本的构图思路（一句话），注明所用风格，如实说明是否做过放大，附上所有成图。

## 构图美学检查清单（2026-09-27 摄影构图研究沉淀，详见 ~/workspace/research_notes/portrait-composition-techniques-20260927-0612/report.md）
定二次构图方案后、执行前，逐条自检：
1. 眼睛压上三分线，脸沿一条垂直三分线偏置，不居中。
2. 视线/面朝方向留 2/3 空间，身后留 1/3；视线撞边框=窒息感。
3. 绝不在关节下剪刀（膝/肘/腕/踝/手指/下巴）；安全点：大腿中部、膝下小腿、腰部、前臂中部。
4. 背景线条（地平线/树枝/屋脊）不穿头颈；穿头了就移动裁剪框错开或裁掉。
5. 头顶留白以"眼睛在上三分线"为准绳；大片空白=死空间，裁掉。
6. 负空间必须把视线送回主体；无信息无方向的空白（空天空、空草地）是死空间。
7. 居中要么彻底对称、要么明确偏三分；"差一点对称"最像失误。
8. 景别先回答"观者需要与人物建立什么关系"：特写=情感亲密、半身=气质对话、中景=姿态故事、全环境=规模孤立；一张照片只讲一件事。
9. 不确定时宁可多留呼吸空间，留多了可再裁，裁错补不回。

## 避雷清单（显廉价的一眼假错误，验图时逐条排除）
1. 塑料皮：纹理被整片抹掉 → 毛孔绒毛必须可见。
2. 外星人眼：眼白死白/虹膜过饱和/亮度违背光照 → 眼白只清洁，眼神光对侧提亮。
3. 没有下眼睑：修眼袋把下眼睑结构线抹掉 → 恐怖谷，只减淡泪沟。
4. 眼下阴影全消：深眼窝填平 → 脸变面具，低不透明度多次减淡。
5. 假牙：纯白无渐变、画面里第一眼跳出来 → 去黄为主。
6. 液化穿帮：下颌改过头卡通化、背景直线被带弯 → 个位数滑块+检查背景。
7. 肤色不统一：脸脖手臂两个颜色 → 修局部时不断取样周围肤色。
8. 违背光源的 D&B：提亮压暗方向与拍摄光源矛盾 → 先判断光源，只增强原有光影。
9. 抠图感虚化：边缘生硬、发丝被吃掉 → 放大检查头发边缘过渡连续。
10. 过饱和（尤其肤色）：皮肤像晒伤 → 用降饱和思路，宁欠勿过。
11. 过度锐化：全图锐化出光晕噪点 → 只锐化眼睛睫毛发丝。
12. 白平衡错误：整图偏蓝偏黄 → 修图第一步先定白平衡。
13. 切关节：裁在手腕/手肘/膝盖/脚踝/脖子 → 裁两关节之间。
14. 头顶一线天：只蹭掉一点点头皮像失误 → 要么不裁要么大胆裁到额头。
15. 柔光滥用：无节制 soft glow、主体边缘光晕 → 效果节制。

## Operating Rules（人像硬规则）
1. 景别由原片信息量决定，不由想要的构图决定。人脸像素不够（约 100px 以下）时，这张就是环境人像的命，不硬裁特写/中景。用户要求技术上不可行的版本时，先直说做不了、给替代方案，不闷头交付次品——盲目服从比拒绝更不专业。（2026-09-27 山顶中景教训：用户说"再试一次中景"我就去裁 150px 的区域，四版全废。）
2. 好修图=看不出来修过。保留皮肤真实纹理：只匀肤色不抹纹理，毛孔和细纹必须可见，绝不做塑料皮。
3. 眼睛 100% 清晰：焦点在眼睛上；眼白只清洁不漂白，提亮只提眼神光对侧；眼袋泪沟只做减淡，保留下眼睑结构线。
4. 不凭空改五官：不换脸型、不放大眼睛、不改鼻梁高度；液化只动脸型、个位数幅度（Chin Height +5~+15、Jawline −3~−8 绝不超过 −10、Face Width −2~−5），改完检查背景直线是否被带弯。特写/半身版放大脸部时必须加指令"严格保持原图面部五官比例、脸型、五官位置一致，不拉宽不压扁不变形"（生成式重绘容易把脸画宽）。若原图脸部太小（约 100px 以下），放大重绘必然脑补出一张"像但不是本人"的脸——此时不出放大型版本，只出保留原脸尺寸的环境版，或明确告知用户风险再做（2026-09-27 山顶半身版 v1 教训：v1 脸已不是本人，作废）。
5. 验图必须单独做脸部身份核对：把成品脸部与原图脸部并排比对，确认是同一个人，不只是"表情没变"。"感觉像"不算数，必须并排比对。（2026-09-27 中景 v2 教训：当时凭感觉声称脸部一致，事后并排比对证实是 AI 重画的脸，v2 作废。另：二次构图裁剪框必须按网格实测坐标计算，不准目测估——v3 的"右三分/上三分"就是目测估偏的。）
6. 肤色统一：脸、脖子、手臂无色差断层；肤色干净红润，不假白、不荧光、不过饱和。
7. 痣/疤/雀斑/美人痣默认保留或只淡化，只去痘印黑头结痂脱皮等临时瑕疵；横过脸的碎发必修，边缘碎发可留；不改变发型。
8. 夜景/暗光人像保留氛围感，暗部可提亮但不准修成白天；降噪适度不涂抹。
9. 二次构图只做裁剪取舍，不准凭空添加原图没有的元素；背景杂物优先裁剪去掉；D&B 只增强原有光影逻辑，先判断光源方向。
10. 一张原图最多出 4 个构图版本；每个版本必须构图思路不同，不准换汤不换药。
11. 分辨率红线：成品最长边不足 2560px（2K）时必须做一次 PIL LANCZOS 2x 插值放大，用户原图不足 2K 也一样处理。

## 诊断模板（第 1 步直接套用）
- 眼睛：对焦是否在眼睛上 / 眼神是否有神 / 眼袋泪沟程度
- 皮肤：痘印斑点位置 / 暗沉或偏色 / 毛孔纹理现状 / 脸脖色差
- 五官：是否需要立体感塑造（鼻影/唇色）/ 牙齿是否偏黄
- 头发：碎发 / 发丝光泽
- 曝光：面部是否死白或死黑 / 背景是否过曝抢戏
- 构图：当前景别 / 眼睛位置 / 头顶留白 / 是否裁在关节处 / 视线方向空间 / 背景干扰物

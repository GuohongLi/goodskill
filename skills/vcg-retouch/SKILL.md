# VCG Retouch（视觉中国修图）

## Purpose
按视觉中国/图库级画质标准修图，附带自动二次构图能力：一张原图可按不同主体/风格裁出多张构图版本。完整画质标准见 `references/quality-standard.md`（21 条：画质硬指标、光影、色彩、景深与背景、构图、后期哲学）。触发词：用户说「视觉中国修图」或「修图」并附上照片。

**环境要求**：你的 AI 助手需要具备图像生成/编辑能力（能按指令重绘或编辑照片）。放大环节用高质量插值放大（如 Lanczos 2x）。

## 画质标准（诊断与验图依据，完整版见 references/quality-standard.md）
主体明确、100% 放大下主体清晰锐利；暗部无明显噪点；高光不死白、暗部不死黑且保留细节；白平衡准确无偏色；饱和度、对比度、锐化、磨皮一律适度（鲜艳不荧光、反差不死黑白、磨皮保留皮肤纹理）；浅景深时杂乱背景虚化干净；地平线端正；无锐化白边、无天空断层与压缩痕迹、无边缘紫边、无脏点污点；后期痕迹不可见。

## Workflow
1. **诊断**：按上面的画质标准列出画质问题（主体明确与否及主体锐度、人像看眼睛、暗部噪点、高光死白/暗部死黑、白平衡偏色、饱和度过艳或发灰、对比度过强或发闷、锐化白边、磨皮过度丢失皮肤纹理、天空断层与压缩痕迹、边缘紫边、脏点污点、地平线歪斜、景深不当、背景杂物抢戏），再诊断构图问题：主体是否居中呆板、边缘有无干扰物、有无死空间（无信息的大片区域）、主体视线/运动方向是否局促、地平线是否歪斜。
2. **定二次构图方案**：根据原图内容定 1–4 个版本，每个版本明确：目标画幅（标准比例 3:2、4:3、16:9、1:1、4:5）、裁掉什么/保留什么、主体放在三分法的哪个位置、留白安排。常用版本模板：
   - 全景校正版：保留原图信息，只做水平校正、去边缘干扰、微调主体位置；
   - 主体特写版：向主体裁近，fill the frame，主体放三分点，去掉死空间；
   - 长焦特写版：主体占满画面，裁掉环境元素，强调压缩感与质感；
   - 画幅适配版：16:9 横版 / 4:5 竖版 / 1:1 方形，按主体朝向选；
   - 留白文案版（图库常用）：主体偏向一侧，另一侧留干净负空间给文案。
   构图法则：三分法优先、主体周围留呼吸感（视线/运动方向多留）、人像眼睛放上三分线、不在关节处裁剪、不贴发际线裁头、少即是多、不裁过头（保留足够像素）。
   若原图构图已很好，可只出 1 个版本；用户明确说"多裁几张"或原图有多个可独立成图的主体时，出 2–4 个版本。
3. **定修图指令**：按修图工作流的顺序组织技术指令——校正（水平/裁剪）→ 曝光（高光/阴影找回细节）→ 白平衡/色彩 → 降噪/去污点 → 主体局部锐化 → 背景虚化或简化（如需要）→ 影调统一。只写技术指令，不加风格化描述词。
4. **执行**：每个构图版本用你的图像生成/编辑工具独立处理一次；每次只输出单张修图成品照片，严禁输出对比拼图或添加任何文字/标题/标注/水印/边框。给工具的 prompt 结构：
   - 第一行：用户原话（「修图」或「视觉中国修图」），原样保留不改写
   - Context 块：先写本版本的二次构图方案（目标画幅、裁剪取舍、主体位置、留白），再按第 3 步顺序列修图技术指令
   - 附上原图作为输入图像，要求保持主体与场景一致
5. **验图**：按画质标准检查每个版本：100% 放大看主体锐度、暗部噪点、天空断层、边缘紫边，确认构图无裁穿主体、无过度 HDR、无塑料感、无后期痕迹。没问题再进入下一步。
6. **分辨率检查与放大**：检查每个成品的最长边，若不足 2560px（2K）则做一次高质量插值放大（如 Lanczos 2x）。放大后快速复验无异常再交付。注意：放大只能改善观感，不能恢复原图不存在的真实细节。
7. **交付**：简述诊断出的问题，说明每个版本的构图思路（一句话），如实说明是否做过放大，附上所有成图。

## 风格选项
默认风格为 VCG 图库级标准（上面的流程）。可选风格：「国家地理封面风」——用户说「国家地理风」「封面风」或明确要求按《国家地理》杂志封面风格修时启用；用户未指定风格时，由你在诊断后按照片内容自主决定用哪种（见下"风格的工作流适配"），两种风格不混用。

默认风的视觉签名——干净与商业感（2026-09-27 实测教训）：VCG 图库片"干净、商业感强"的观感支柱之一是深色锚点。画面里的深色区域（沥青路面、暗部、阴影）必须压得够深（保留材质纹理、不糊成死黑），与亮部拉开利落的对比，画面才"透"。反面：把黑色提太高（如路面发灰）会让整图发"浮"、显脏。执行默认风时，先找到深色锚点并确认它够深，再定整体影调；"暗部不死黑"不等于"暗部提亮"——提亮只为找回细节，不为把黑洗成灰。

### 国家地理封面风（2026-09-27 研究沉淀，基于 Nat Geo 官方封面回顾、总编辑 Susan Goldberg 与摄影总监 Dan Westergren 的一手访谈/声明）
1. 构图沿用 VCG 自适应二次构图，不强制竖版：先判断"这张最美的地方"再定景别（特写/半身/环境/全景都是候选）；竖幅只是候选画幅之一，不做刊头/封面行留白——学的是视觉风格，不是做真封面。
2. 单一强主体：画面只允许一个视觉主角（山峰/瀑布/动物/人物剪影），主体约占画面 25–40%；主体涣散则用裁剪收紧，收不紧就直接判定"这张不适合封面风"并告诉用户，给默认风格替代。
3. 留白：至少保留一处 ≥20% 的呼吸区（干净天空/水面/暗部），元素不与画面边缘"打架"。
4. 前景/中景/远景至少具备两层；用前景岩石、河流、道路做引导线指向主体；地平线/主体落在三分线上。
5. 影调 tonally compressed：高光压缩保留层次（高光 −30~−50），阴影提亮保留细节（阴影 +20~+40），高光不死白、暗部不死黑；局部减淡加深只做轻微（±0.3~±0.7 EV），边缘压暗 ≤ −0.5 EV，不出光晕；禁 HDR 观感与强色调映射。
6. 色彩 Kodachrome 血统——浓郁但真实，"增强而非改变"：用 Vibrance 而非 Saturation（Vibrance +10~+25，Saturation 0~+10，全局饱和封顶 +30）；黄金时刻白平衡锁 Daylight 保暖调，不把暖色"纠正"掉；天空靠降蓝色明度加深（−10~−25）而非狂加饱和，禁不自然死蓝；高光可带极轻微暖调，阴影保持中性；禁重度 teal-orange 电影感；禁创意滤镜一键套用（Nat Geo 摄影总监原话："No. Please stop."）。
7. 对比与清晰：对比度中等（+10~+25），靠局部塑形而非全局猛拉；Clarity +5~+15，Dehaze 仅雾霾天 +5~+15，禁 Clarity >+30 的数码雕刻感；雾气/空气透视是氛围资产，不除到发干。
8. 锐化降噪：标准输出锐化（数量 40–70、半径 0.8–1.2、蒙版 60+ 只锐化边缘）；只去传感器噪点，保留颗粒感，不做塑料平滑。
9. 在场感三问（验图时逐条回答，任一"否"则回退）：① 是否忠实呈现了摄影师按下快门时所见？② 是否呈现了身临其境那一刻的感受？③ 与原图并排，差异是否落在"增强已有内容"而非"改变图像"区间？
数值说明：具体数值区间是根据 Nat Geo 编辑原则（"轻微""增强而非改变""忠实呈现所见"）转化的可操作建议，非 Nat Geo 官方公布数字；定性红线（禁 HDR、禁滤镜）有 Nat Geo 总编辑/摄影总监一手声明来源。
风格强度校准（2026-09-27 实测反馈）：晴天片按上面标准参数修出的封面风与默认风肉眼几乎无差；调门开大一档（天空降蓝明度更多、云层对比更强、绿色更深沉）的版本才被认可为"国家地理风"。执行封面风时，风格差异必须做到肉眼可辨，宁可往戏剧化推一点，也不要修成"看不出区别"的温和版——但仍禁 HDR、禁滤镜、禁改变天气。
忠实度铁律（2026-09-27 雾气片教训）：调门开大绝不等于发明场景——曾把均匀平雾"脑补"成层叠云海和远山轮廓，被指出"明显不是一个场景"后作废。背景没有的结构不准造：平雾保持平雾、没有的云层不准加、没有的远山轮廓不准画；厚重感只许用在前景主体上。验图时必须拿原图逐项对比背景，构图对上不等于场景对上。

### 风格的工作流适配
- 风格选择：用户未指定风格时，诊断后按照片内容自主决定——封面风适合单一强主体明确、有呼吸区与前景/中景/远景层次、有氛围感潜力（雾气、戏剧性光线、情绪感）的照片；默认风适合需要干净图库感、主体较涣散、或纪实记录类的照片。选定后在交付时一句话说明理由；用户明确指定风格时按指定的走。
- 诊断时加一条：判断原图是否适合所选风格；不适合则直说并给替代。
- 定构图方案时：封面风沿用自适应二次构图，不强制竖版，不做刊头留白。
- 定修图指令时：在 prompt 的 Context 块中注明"风格：国家地理封面风"，按上面 9 条组织技术指令；仍只写技术指令，不加风格化描述词。
- 验图时：封面风加跑"在场感三问"。

## Operating Rules
1. 修图是还原和优化，不是重绘：保持原图主体和氛围，后期痕迹不可见；二次构图只做裁剪取舍，不准凭空添加原图没有的主体。
2. 夜景/蓝调时刻保留夜感：暗部可提亮找回层次，但不准修成白天。
3. 降噪适度，保留材质真实纹理；锐化只做局部主体，不过锐。
4. 杂乱抢戏元素（电线杆、高压塔、垃圾桶、杂车等）优先用裁剪去掉，裁不掉的再做减法去除。
5. 人像/特写：重点关注眼睛锐度，裁剪避开关节处，用浅景深把杂乱背景化开；风光：地平线端正，保持深景深全画面清晰，高光不死白暗部不死黑。
6. 饱和度、对比度、锐化、磨皮一律适度：鲜艳不荧光、反差不死黑白、磨皮保留皮肤纹理。
7. 一张原图最多出 4 个构图版本；每个版本必须构图思路不同，不准换汤不换药。交付前把各版本并排比对，构图雷同的作废重做。
8. 大幅裁剪（如长焦压缩版）先用代码（PIL 等）按方案实打实裁出底图，再把裁好的图送图像模型修——裁剪是确定性操作，不交给生成模型"理解"，否则模型可能偷懒重画全景导致版本雷同。
8. 分辨率红线：成品最长边不足 2560px（2K）时必须做一次放大（AI 超分优先，高质量插值兜底），用户原图不足 2K 也一样处理。
